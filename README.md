# 📖 उल्लास ULLAS — अक्षर ज्ञान (Akshar Gyan)

**Learn to read Hindi and English from absolute zero — with voice, pictures and colours.**

This repository contains a free, offline-capable literacy website built for adults who never
got the chance to go to school and cannot read *any* text yet. Every screen speaks its
instructions aloud in Hindi, and all navigation uses big icons — so a first-time learner can
use it entirely on their own.

> Made with love for a mother in Jodhpur ❤️ — and for every adult learning to read.

## ▶️ The website lives in the [`docs/`](docs/) folder

- **[docs/README.md](docs/README.md)** — full guide: what's inside, how to deploy,
  how to set up the learner's phone, first-session tips, and how to customise the words.

## 🚀 Quick deploy (GitHub Pages, free)

1. **Settings → Pages**
2. Source: **Deploy from a branch** → Branch: the default branch → Folder: **`/docs`** → Save
3. Live in ~1 minute at **`https://prathit-mukesh.github.io/ULLAS/`**

## What it teaches

| | हिंदी | English |
|---|---|---|
| 1 | स्वर (13 vowels) | Capital letters A–Z |
| 2 | व्यंजन (36 consonants) | Small letters a–z |
| 3 | मात्रा — interactive बारहखड़ी (क + ◌ा = का) | Two-letter blending (g + o = go) |
| 4 | शब्द जोड़ो — घ + र = घर 🏠 | Small words (c-a-t = cat 🐱) |
| 5 | मात्रा वाले शब्द (पानी, रोटी…) | Everyday words (milk, book…) |
| 6 | वाक्य — daily-life sentences | Simple sentences |
| 7 | खेल — listen-and-tap game with ⭐ stars | खेल — same, in English |

Every letter, word and sentence is tappable and spoken aloud; words carry emoji pictures;
letters are colour-coded (red स्वर, blue व्यंजन, green मात्रा); progress and stars are saved
on the phone. Plain HTML/CSS/JS — no build step, no accounts, no ads, works offline after
the first visit.
